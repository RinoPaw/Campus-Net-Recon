# 04-流量路径与边界验证

> 状态：占位待写。本篇计划整理“校内互联、公网访问、代理转发”三类流量在不同登录状态下的路径差异。

## 4.1 想回答的问题

- 未登录、已登录但未开通套餐、已登录并可访问公网时，流量边界分别在哪里？
- 校内设备互通和公网访问是否由不同策略控制？
- 代理软件的局域网访问能力在这个场景中扮演了什么角色？
- 哪些现象只能说明“可达”，不能说明“路径被改变”？

## 4.2 记录方式

建议把每个场景拆成三层：

1. 校内连通性：网关、认证页、同网段设备、跨网段设备。
2. 公网连通性：DNS、HTTP/HTTPS、ICMP。
3. 转发路径：第一跳、TTL、代理入口、出口设备。

## 4.4 写作提醒

这一篇容易被误读成“绕过指南”，所以写作时需要把重点放在协议观察和边界验证上：

- 多写现象、少写复现动作。
- 不记录账号、套餐、认证细节。
- 不给出会影响校园网管理策略的规避步骤。
- 把每个结论都标明“已验证”或“仍是推测”。
