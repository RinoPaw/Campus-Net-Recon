# Campus-Net-Recon

校园网环境观察与网络协议学习笔记。

这个仓库记录一次从“奇怪的子网掩码”开始的校园网排查过程：我用笔记本和手机观察 DHCP、网关、ARP、TTL、AP 隔离等现象，并把每一次实验的环境、命令、结果和推测留下来。

这里更像是一份可持续更新的实验日志，而不是教程。它关注“现象为什么会这样”，不记录账号、个人隐私，也不提供绕过认证、计费或访问控制的操作指南。

## 项目边界

- 仅记录本人已获授权接入环境中的观察与学习过程。
- 命令和截图只用于解释基础网络机制，例如 CIDR、ARP、Proxy ARP、TTL、DHCP、AP/AC。
- 不收集、公开或利用他人设备信息；文档中的 IP、MAC、账号相关内容应尽量脱敏。
- 如实验结论可能影响校园网正常运行，应停止公开复现实操细节，只保留原理分析和风险提示。

## 写作结构

后续每篇尽量保持同一种节奏：

1. 背景：当时遇到了什么问题。
2. 环境：设备、网段、登录状态、所在位置。
3. 操作：做了哪些观察或验证。
4. 现象：实际看到的输出和结果。
5. 推测：根据现象得到的解释。
6. 边界：还不能证明什么，下一步该怎么验证。
