# 00-记录规范与术语

这一篇是整个仓库的“写作说明书”。后续每次新增实验记录，都尽量按同一套结构写，这样读起来会更像一条清晰的探索路线，而不是零散笔记。

## 0.1 记录边界

- 只记录自己有权限接入的网络环境。
- 不公开账号、手机号、精确设备身份、完整 MAC 地址等个人或第三方信息。
- 不写可直接用于绕过认证、计费或访问控制的步骤。
- 当实验可能影响他人网络体验时，停止继续测试，只保留现象描述和原理分析。

## 0.2 单篇模板

```md
# 编号-标题

> 本篇结论：一句话说明这篇观察到了什么。

## 背景

为什么开始这个实验，遇到了什么异常现象。

## 实验环境

- 位置：
- 设备：
- 登录状态：
- IP / Prefix Length / 网关：
- 相关工具：

## 操作与现象

记录命令、输出、截图摘要或表格。

## 推测

根据现象解释可能的网络机制。

## 未解问题

哪些结论还不能下死，下一步需要怎么验证。
```

## 0.3 常用术语

| 术语 | 说明 |
| :--- | :--- |
| CIDR | 用 `/数字` 表示网络前缀长度，例如 `/15` 等价于 `255.254.0.0`。 |
| Prefix Length | 前缀长度，表示子网掩码中连续 `1` 的数量。 |
| 网关 | 当前设备离开本地网段时默认交给的下一跳设备。 |
| DHCP | 自动分配 IP、网关、DNS 等网络参数的协议。 |
| ARP | 在 IPv4 局域网中根据 IP 查询 MAC 地址的协议。 |
| Proxy ARP | 网关代替其他地址回应 ARP 请求，让设备误以为很多 IP 都在二层可达。 |
| TTL | IP 包的生存时间。每经过一跳三层设备通常会减 1。 |
| AP | 无线接入点，通常就是实际连接的 Wi-Fi 发射设备。 |
| AC | 无线控制器，用于集中管理多个 AP。 |
| BSSID | 某个 AP 无线接口的标识，通常表现为一个 MAC 地址。 |

## 0.4 记录清单

新增文章前，可以先检查这些信息是否齐全：

- 是否说明了实验位置和登录状态。
- 是否脱敏了个人信息和设备标识。
- 是否区分了“观察结果”和“个人推测”。
- 是否写清楚了还不能证明的部分。
- 是否避免给出会影响他人网络或违反规则的复现实操。
