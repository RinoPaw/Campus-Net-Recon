# 11-Win7 第二接入点：192.168.243.0/24 观察

> 观察日期：**2026-11-10**，依据当时通过 Reinor 对第二台个人/获授权 Win7 的只读命令结果整理；于 2026-11-13 补录。原始会话中未保存统一的精确采样时间，因此本文不把这些单次测量表述为连续监测。设备在本仓库中以 `win7-2` 匿名表示，完整 MAC 和主机名不公开。

## 11.1 背景与实验环境

在 [05](05-Win7有线接入网关与跨域回程观察.md) 中，第一台 Win7 的有线地址为 `192.168.236.49/24`。第二台 Win7 接入不同的私有网段，可用于检查有线接入网关的共同特征、校园内部路径和 `1.1.1.1` 异常是否仅发生在单台机器。

| 项目 | 当时观察 |
| --- | --- |
| 设备 | Win7，Realtek PCIe GBE Family Controller，约 1 Gbps |
| IPv4 | `192.168.243.77/24` |
| 默认网关 | `192.168.243.254` |
| DNS | `8.8.8.8` |
| 地址配置 | DHCP 关闭，静态 IPv4 |
| 网关 ARP | OUI `60:0B:03`（H3C 注册前缀） |
| 网卡 MTU | 1500 |
| WinHTTP 系统代理 | 未启用 |

这里的 `win7-2` 是研究中的设备别名。没有获取交换机管理面、端口 VLAN 或现场地理定位；IP/24 只代表此时主机的 IPv4 接入配置。

## 11.2 路由与不同私有网段

本机默认下一跳为 `192.168.243.254`。当时路由表中还发现与 `192.168.223.254`、`192.168.228.254`、`192.168.235.254` 相关的**持久路由记录**。它们可能来自过去的网络配置，不能把这些历史项直接视为当前活动流量的路径，需按各条路由的目的前缀、掩码和 metric 分析。

对几个已知校园网地址的 `tracert -d` / ICMP 结果，观察到上游的共同节点：

```text
192.168.243.77 (Win7)
  -> 192.168.243.254       （本地默认网关）
  -> 192.168.229.253       （逐跳记录）
  -> 49.122.23.254         （逐跳记录）
  -> 10.0.2.97 / 10.0.4.2 （在部分目标路径中）
  -> 10.201.255.254（6 跳）/ 10.202.255.254（7 跳）
     / 10.203.255.254（6 跳）
```

对目的地址的追踪未必走完全相同的后续路由。`49.122.23.254` 属于登记为 CERNET 的地址段，但地址归属不足以标定交换机型号、实体位置或 NAT 点。

在 `192.168.223/228/235/236/243` 等已知网段，多个 `.254` 地址能迅速响应 Ping，回复 TTL 约 255。这与共同网关设备组、三层 SVI、虚拟网关等模型相容；**不能据此断言这些 IP 都属于同一台物理设备**。

## 11.3 目标公网 IP 的异常响应

当时的少量 ICMP 样本如下。延迟是短时观察值，并非长期质量指标。

| 目标 | 典型 RTT | 回复 TTL | 观察 |
| --- | --- | --- | --- |
| `1.1.1.1` | 0–4 ms | 61 | 逐跳追踪约第 4 跳到达 |
| `1.1.1.2` | 小于 1 ms | 250 | 与 `1.1.1.1` 不同的回复 TTL |
| `1.0.0.1` | 约 83 ms | 46 | 明显高于前两项 |
| `1.1.1.3` | 约 85–86 ms | 46 | 远端路径特征 |
| `8.8.8.8` | 约 183 ms | 102 | 当次 Ping 样本 |
| `223.5.5.5` | 约 16 ms | 111 | 另有 DNS 查询曾超时 |

对 `1.1.1.1` 与 `1.1.1.2` 的 TCP 53/443 端口进行有限连接测试，连接被拒绝；在相同网络中，`1.0.0.1:53` 可连接。这提示同属公开服务地址的不同目的 IP 被采取了**不同的转发或应答行为**。

目前仅能确认：这些结果**不是单纯由本机 DNS 解析导致**，因为测试直接针对 IP；至于是否由策略路由、内部路由注入、防火墙拒绝或其他网络设备应答，需要更直接的证据。不能仅凭 RTT/TTL 判定目标真实位于校园内部，也不能断定真实 Cloudflare 服务收到了连接尝试。

## 11.4 已证实 / 待证实

**已证实的当次观察：** 第二台 Win7 的 `192.168.243.0/24` 静态接入；网关 MAC OUI 与第一台 Win7 相同；多个校园已知网关地址可达；`1.1.1.1` 与 `1.1.1.2` 的异常低延迟、特殊 TTL 和 TCP 拒绝。

**尚未证实：** 历史持久路由的来源、这些 `.254` 的物理归属、低延迟公网 IP 的实际应答者、上游策略的实施位置、是否存在按校区/认证状态变化的匹配规则。
